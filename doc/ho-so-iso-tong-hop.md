## Quy trình sản xuất hàng gỗ gia dụng (QT.04 – Kiểm soát quá trình sản xuất)

1. **Xử lý nguyên liệu:** gỗ tấm → cưa ngắn → phôi gỗ → ghép → cưa rong → cưa ngắn → gỗ thanh
2. **Cưa xẻ:** bào 2 mặt → cưa rong → nhám thùng → khoan định vị → tiện / CNC → cưa lọng → máy tubi
3. **Xử lý bề mặt:** nhám thùng → bo cạnh → nhám băng → chà lông → nhám cốc → đánh bóng → kiểm tra → sơn bóng
4. **Lắp ráp & đóng gói:** lắp ráp → in logo → dán tem → đóng gói
